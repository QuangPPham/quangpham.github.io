Project Description
======
Autonomous robots often face environments with geometric, semantic, and temporal requirements, motivating the use of formal specification frameworks such as Linear Temporal Logic (LTL) to represent high-level tasks. In this project, we use model-free safe RL algorithms to devise control strategies for robots subjected to LTL-based rewards and constraints.

Responsibilities
======
- Coded a Product MDP platform to allow for quick algorithm experimentation.
- Defined LTL-based rewards and constraints into an open-source safeRL repository for training.
- Developed core perception capabilities of a robot arm, allowing for hardware testing.
