Project Description
======
Reinforcement Learning has been extensively applied to legged robots, resulting in extremely robust locomotion controllers and acrobatic behaviors such as jumping, parkour, and handstand for quadrupeds. Despite this progress,no method has been devised for jumping on sloped terrains. In this project, I investigated whether existing frameworks can accomodate jumping on slopes, and proposed a learning-based method for doing so.

Responsibilities

- Coded a Gymnasium-based quadruped environment in MuJoCo
- Designed the learning architecture
